# 圖片快速分類工具

使用 Python 製作的桌面應用程式，透過圖片預覽、分類快捷鍵與重新命名功能，協助使用者快速整理圖片。

目前版本：**v0.1**

## 功能

- 輸入路徑或瀏覽選擇圖片資料夾。
- 預覽圖片，保持原始比例縮放，並依 EXIF 資訊修正顯示方向。
- 顯示檔名、圖片尺寸與目前清單位置。
- 自動將子資料夾建立為分類按鈕。
- 使用數字鍵 `1～9` 快速分類。
- 分類後自動顯示下一張圖片。
- 重新命名時保留原始副檔名。
- 支援同時重新命名與分類。
- 在程式內新增分類資料夾。
- 復原本次執行期間的移動與重新命名操作。
- 遇到同名檔案時，自動加上編號，避免覆蓋。

## 執行環境

- Python 3.10 以上
- Tkinter
- Pillow

本專案以 Windows 使用情境為主，提供 Python 原始碼，尚未打包為 `.exe`。

## 安裝與執行

### 1. 建立 Anaconda 環境

若尚未建立環境，執行：

```bash
conda create -n image-sorter python=3.12
```

### 2. 啟用環境

```bash
conda activate image-sorter
```

### 3. 切換至專案資料夾

以下以 PowerShell 為例，請依實際位置修改路徑：

```powershell
cd C:\Code\python\image_sorter
```

### 4. 安裝套件

```bash
python -m pip install -r requirements.txt
```

### 5. 啟動程式

```bash
python main.py
```

之後使用時，只需啟用環境、切換至專案資料夾，再執行 `python main.py`。

## 使用方式

### 載入圖片

1. 在路徑欄輸入圖片資料夾位置，按下「載入」。
2. 或按下「瀏覽」，直接選擇資料夾。
3. 程式讀取資料夾第一層的圖片，並依檔名排序。

子資料夾中的圖片不會加入待分類清單。

### 分類圖片

程式會依原資料夾下的子資料夾建立分類按鈕。

例如，選擇的資料夾為 `D:\圖片待整理`，其中有「人物」與「風景」兩個子資料夾，畫面就會出現對應按鈕。

點擊分類按鈕或按下對應數字鍵後，目前圖片會移入該子資料夾，並自動顯示下一張。

> 分類會實際移動原始檔案，不是建立副本。

前九個分類支援數字快捷鍵；其餘分類可使用滑鼠點擊。新增分類時，既有快捷鍵對應保持不變。

### 重新命名

1. 在「新檔名」輸入框修改名稱，不必輸入副檔名。
2. 按下 `Enter` 或「套用名稱」，只重新命名目前圖片。
3. 也可以直接點擊分類按鈕，同時完成改名與移動。

例如，原始圖片為 `IMG_001.png`，輸入 `海邊夕陽` 後，會改名為 `海邊夕陽.png`。

若目標名稱已存在，會自動使用 `海邊夕陽_1.png` 等名稱。

### 新增分類

點擊「＋ 新增分類」，輸入名稱，即可在目前載入的資料夾下建立子資料夾。

### 略過圖片

點擊「略過／下一張」只會切換預覽，圖片仍保留在待分類清單中。

切換圖片時，尚未套用的檔名修改會被捨棄。

### 復原操作

按下「復原」或 `Ctrl + Z`，可撤銷上一次移動或重新命名，並支援連續復原。

- 復原紀錄只保留在本次程式執行期間。
- 重新載入資料夾或關閉程式後，復原紀錄會清除。
- 新增分類資料夾不在復原範圍內。
- 若復原的目標位置已有同名檔案，程式會停止並提示，不會覆蓋。

## 快捷鍵

| 快捷鍵 | 功能 |
| --- | --- |
| `1～9` | 分類至對應子資料夾 |
| `←` | 上一張 |
| `→` | 下一張 |
| `F2` | 選取檔名，開始編輯 |
| `Enter` | 在檔名輸入框中套用名稱 |
| `Esc` | 離開輸入框，回到圖片區 |
| `Ctrl + Z` | 復原上一次檔案操作 |

在文字輸入框中編輯時，數字分類、左右鍵切圖與檔案復原快捷鍵會暫停，避免誤觸。

## 支援格式

- JPG / JPEG
- PNG
- BMP
- WEBP
- GIF
- TIF / TIFF

GIF 僅預覽第一格，TIFF 僅預覽第一頁；分類與改名仍保留完整原始檔案。

目前不支援 HEIC、SVG、RAW，也不讀取符號連結。

## 注意事項與目前限制

- 首次使用建議先以少量圖片副本測試。
- 使用期間，請避免透過其他程式同時移動或修改同一批圖片。
- 預覽不會修改圖片原始內容。
- 大型圖片載入時可能短暫等待。
- 尚未提供手動縮放、拖曳平移與跨次啟動的復原紀錄。
